# 반복 그래픽 명령 7종

기존 `laya-ae` 실행기에 연결되어 있어 재설치 없이 사용합니다. 아래 명령은 새 그래픽을
현재 활성 컴포지션에 추가합니다. 먼저 AE에서 작업할 컴포지션을 클릭하세요.
명령 전체를 따옴표로 묶으면 `#RRGGBB` 색상과 공백을 안전하게 전달할 수 있습니다.

```sh
laya-ae --list
laya-ae --dry-run '방사형 패턴 만들어줘 개수 36 반지름 260'
```

`--dry-run`은 문장과 수치만 검사합니다. 실제 레이어 선택·현재 시간·기존 애니메이션은
실행 직전 AE 상태를 읽어 검사합니다. 모든 실행은 새 job을 쓰고 결과를 검증합니다.

## 1. 방사형 배열

```sh
laya-ae '방사형 패턴 만들어줘 개수 48 반지름 230 크기 12 길이 95 회전속도 12 색 초록색'
laya-ae '방사형 배열 도형 원 개수 24 반지름 220 크기 30 색 #FF6699'
```

| 옵션 | 기본값 | 의미 / 범위 |
| --- | --- | --- |
| 개수 | 36 | 도형 수, 1~180 |
| 반지름 | 260 | 중심에서 도형 중심까지 px, 0~4000 |
| 도형 | 막대 | 막대 / 원 / 사각형 |
| 크기 | 14 | 막대 폭 또는 원 지름·정사각형 크기 px |
| 길이 | 90 | 막대 길이 px |
| 회전 | 0 | 전체 배치 시작 각도 |
| 회전속도 | 0 | 전체 회전, 도/초, -360~360 |
| 색 | 민트 | 색 이름 또는 #RRGGBB |

도형 그룹들이 들어 있는 편집 가능한 Shape Layer 하나를 만듭니다.
이전 대화의 원 그리기도 편의 명령으로 지원합니다.

```sh
laya-ae '초록색 원 그려줘'
laya-ae '지름 180 빨간색 원 그려줘'
```

## 2. 흔들리는 격자

```sh
laya-ae '흔들리는 격자 만들어줘 행 10 열 18 간격 56 크기 13 흔들림 42 속도 0.25 시드 7'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 행 / 열 | 8 / 14 | 각각 1~30, 총 400점 이하 |
| 간격 | 60 | 점 사이의 기본 간격 px |
| 크기 | 12 | 점 지름 px |
| 흔들림 | 35 | 수직 파동 진폭 px, 0~1000 |
| 속도 | 0.3 | 초당 파동 횟수, 0~5 |
| 색 / 시드 | 하늘색 / 1 | 색과 재현 가능한 파동 위상 |

점마다 위상이 다른 수직 사인 파동입니다. 속도 0.25는 4초 주기로 반복합니다.
Shape Layer의 Contents에서 점별 위치 표현식을 편집할 수 있습니다.

## 3. 윤곽선 겹치기

```sh
laya-ae '윤곽선 패턴 만들어줘 선 40개 반지름 320 왜곡 60 두께 2 속도 0.125 시드 9'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 선 | 32 | 닫힌 윤곽선 수, 1~100 |
| 반지름 | 320 | 가장 바깥 선의 기본 반지름 px |
| 간격 | 자동 | 선 사이 기본 간격 px; 생략하면 반지름에 맞춤 |
| 왜곡 | 55 | 유기적인 굴곡의 진폭 px |
| 두께 | 2 | 선 두께 px |
| 속도 | 0.125 | 초당 변형 주기, 0~2; 기본 8초 반복 |
| 색 / 시드 | 민트 / 1 | 색과 재현 가능한 형태 위상 |

선마다 96개 꼭짓점의 경로를 만들고 고정된 수식으로 변형합니다. 반지름·간격·왜곡의
조합으로 안쪽 선이 뒤집힐 위험이 있으면 실행 전에 거절합니다. `속도 0`은 정지 형태입니다.

## 4. 규칙 있는 흩뿌리기

```sh
laya-ae '도형 흩뿌리기 개수 140 최소크기 8 최대크기 54 팔레트 네온 분포 중앙 시드 42'
laya-ae '흩뿌리기 개수 60 도형 사각형 팔레트 파스텔 시드 12'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 개수 | 80 | 도형 수, 1~400 |
| 최소크기 / 최대크기 | 8 / 60 | 도형 크기 범위 px |
| 도형 | 원 | 원 / 사각형 |
| 분포 | 균등 | 균등 / 중앙 |
| 팔레트 | 네온 | 네온 / 파스텔 / 모노 |
| 시드 | 42 | 0~2147483647 정수 |

위치·크기·회전·팔레트 내 색·불투명도를 정해진 범위에서 변화시킵니다.
동일한 컴포지션 크기·옵션·시드는 같은 그래픽을 재현합니다.

## 5. 텍스트 반복 배열

```sh
laya-ae '텍스트 반복 "WAVE" 행 5 열 6 가로간격 230 세로간격 130 글자크기 48 회전 -8'
laya-ae '텍스트 격자 문구 "HELLO WORLD" 행 3 열 4 글자크기 36 색 노란색'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 문구 | WAVE | 120자 이하; 띄어쓰기가 있으면 안쪽 따옴표 사용 |
| 행 / 열 | 5 / 6 | 총 100개 이하 |
| 가로간격 / 세로간격 | 230 / 130 | 타일 중심 사이 간격 px |
| 글자크기 | 48 | 폰트 크기 |
| 회전 | 0 | 타일별 회전 각도 |
| 색 | 흰색 | 색 이름 또는 #RRGGBB |

각 타일을 개별 Text Layer로 만들고 중심을 맞춥니다. 생성 후 전체 타일이 선택되어
바로 순차 등장을 적용할 수 있습니다. 글꼴은 AE의 현재 기본 글꼴을 사용합니다.

## 6. 잔상 쌓기

움직이는 2D 레이어 하나를 선택합니다.

```sh
laya-ae '선택 레이어 잔상 만들어줘 개수 12 간격 0.08 감쇠 0.84'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 개수 | 8 | 원본 외 잔상 복제 수, 1~32 |
| 간격 | 0.08 | 잔상마다 누적되는 시간 지연 초 |
| 감쇠 | 0.8 | 뒤 잔상의 불투명도 배율, 0.05~1 |

복제 레이어는 원본의 이전 위치·앵커·크기·회전·불투명도를 따라갑니다. 원본을 계속
수정하면 잔상도 따라옵니다. 원본이 정지해 있으면 잔상도 겹쳐 보입니다.
텍스트 내용·경로 변형·영상 프레임·이펙트 자체의 시간을 지연시키는 기능은 포함하지 않습니다.
카메라·라이트·3D·위치 차원이 분리된 레이어는 지원하지 않습니다.

## 7. 순차 등장

정적인 2D 레이어 2개 이상을 선택하고 재생 헤드를 등장 시작 지점에 둡니다.

```sh
laya-ae '선택 레이어들 0.05초 간격으로 등장시켜줘'
laya-ae '순차 등장 간격 0.06 시간 0.65 이동량 80 순서 위에서'
laya-ae '순차 등장 간격 0.04 시간 0.5 순서 랜덤 시드 12'
```

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| 간격 | 0.05 | 레이어 사이 시작 시각 차이 초 |
| 시간 | 0.6 | 각 레이어의 등장 소요 시간 초 |
| 이동량 | 60 | 최종 위치보다 아래에서 시작하는 거리 px; 음수 가능 |
| 순서 | 위에서 | 타임라인 기준 위에서 / 아래에서 / 랜덤 |
| 시드 | 1 | 랜덤 순서 재현 값 |

위치·불투명도 두 점과 부드러운 이징을 만듭니다. 끝 위치와 끝 불투명도는 유지합니다.
기존 위치·불투명도 키프레임/표현식이 있는 레이어, 잠긴 레이어, 3D/분리 위치는
변경하지 않고 실행 전에 거절합니다. 키프레임 전체가 레이어와 컴포지션 길이 안에
들어가야 합니다. 반복 실행은 새 레이어에 적용하세요.

## 공통 동작

- 생성 명령을 다시 실행하면 새 그래픽을 추가합니다. 기존 결과를 자동 교체하지 않습니다.
- 일반 패턴은 Shape Layer 한 개, 텍스트 격자는 타일별 레이어, 잔상은 복제 레이어를 만듭니다.
- 실행 후 레이어 수는 최대 200개입니다. 큰 패턴은 별도 컴포지션을 사용하세요.
- 색 이름: 초록색/녹색, 빨간색/빨강색, 파란색/파랑색, 흰색/하얀색, 검은색/검정색, 노란색/노랑색.
- `partial`/timeout/결과 없음이면 같은 작업을 재전송하지 말고 결과와 현재 상태를 먼저 확인합니다.
- Shape Layer의 내부 표현식은 도형 Contents 안에 있으므로 기본 상태 조회의 레이어 Transform 표현식 목록에는 나오지 않습니다.

경로 표현식은 [Adobe 표현식 언어 문서](https://helpx.adobe.com/after-effects/desktop/work-with-expressions/expression-language-reference/expression-language-reference.html)의 `createPath`를 사용합니다.
